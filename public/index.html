常见问题

需要会写代码吗？

不需要。你只管提想法，规格设计、代码生成、编译全自动完成。

生成的模组怎么用？

安装 Fabric Loader + Fabric API，把下载的 jar 放进 .minecraft/mods 即可。支持 1.20 / 1.20.1 / 1.20.2 / 1.20.4 / 1.21 / 1.21.1 / 1.21.4，以及 26.1 / 26.2 / 26.3（26.x 需套餐或单次购买）。

能做多复杂？

当前支持：物品、剑 / 镐 / 斧 / 锹 / 锄（六种材质档）、食物、方块，自动带配方和贴图。护甲、生物、附魔正在路上。

数据安全吗？

仅用邮箱注册；AI Key 保存在服务端，不暴露给浏览器；构建在一次性云端容器进行。
